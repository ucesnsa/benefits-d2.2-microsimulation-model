# europe/docs — EU foundation documentation

The EU cross-country foundation, common to Spain, Italy, and Greece:

- `FOUNDATION.md` — the master EU document (coverage map, provider layer, Analyst dial specification, decisions and method, year convention).
- `PROVIDER_EVIDENCE_EU.md`, `PROVIDER_DECISIONS.md` — native provider evidence and the settled decisions.
- `PROVIDER_TOOLREADY_2024.md` — the 2024-equivalent tool-ready provider layer.
- `references.bib` — the EU-cited bibliography (subset; other sources are cited inline in the documents above).
- `DATA_ISSUES_FOR_TECHNICAL_REPORT.md` — the models' data limitations, cross-country.
- `BASELINE_VALIDATION.md` — the three models against the published EUROMOD baseline.
- `CONVERSION_RECORD.md` — how EU-SILC becomes EUROMOD input, per country.
- `REEMIT_PROVENANCE.md` — how the EU fiscal layer is reproduced.
- `VALUATION_CHAINS.md` — how every provider outcome value is built, figure by figure.
- `LIKE_FOR_LIKE_SWEEP.md` — the comparability sweep the Italy tool face cites.
- `benefit_adjustments.json`, `ppp_deflator_pull_2026-08-03.json` — the calibration adjustments and the PPP and deflator source pull.

Engine: **EUROMOD v3.8.6**. Data: EU-SILC 2024 wave (2023 income reference year), not in this repository.
